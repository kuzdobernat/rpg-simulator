# Felhasználói Történetek (User Stories)

1. **Többféle karakterkaszt használata:** Játékosként szeretnék Harcos, Mágus, Íjász, Orgyilkos és Paladin karakterek közül választani vagy újakat létrehozni.
2. **Szabad párosítás az arénában:** Játékosként szeretném kiválasztani a listából, hogy melyik két szereplő küzdjön meg egymással (akár 1 körös csapásban, akár végsőkig tartó párbajban).
3. **Felszerelések használata:** Játékosként szeretném a kiválasztott karakteremet varázsfegyverekkel és pajzsokkal felszerelni futásidőben.
4. **Hátizsák kezelése:** Játékosként szeretném a tárgyaimat súly vagy érték szerint rendezni az inventoryban.
5. **Állapot mentése és betöltése:** Játékosként szeretném elmenteni és visszatölteni a karakterek állapotát JSON fájlba.
